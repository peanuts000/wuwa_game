# 纸偶冒险剧场 · UI 与美术概念

日期：2026-10-10。适配本项目的三消、技能牌与分叉探索玩法。

这是参考《鸣潮》「团团勇者大乱斗」与「荣耀之丘」视觉语言形成的融合设计，属于本项目概念方案，非官方界面。设计图中的角色状态、费用、生命与金币等样例数值仅供视觉示意，不作为数值配置。

## 设计方向

以「团团」活动的奶油纸、紫色包边、票券、缝线、星星吊饰构成纸偶舞台；以「荣耀之丘」的灰黑卡牌信息面板、浅金细边、圆形费用徽章组织战斗信息。纸张与团子角色负责亲切感，清晰的深色信息区负责读数。

背景采用低对比纸纤维与舞台层叠，边角使用撕边、票券缺口和少量缝线。星星吊饰集中于页头和画面边缘，棋盘格、敌人意图、卡牌正文保持简洁。团子纸偶保留大头轮廓、白色外沿与清楚的表情，增加少量纸片投影和折叠支架感。

## 三张设计图

### 1. 战斗界面

[战斗设计图](../output/ui_concepts/battle-ui-v1.png)，16:9。

- 左侧：英雄纸偶、角色等级、战斗生命条、格挡、所选四属性技能点与三格补给。探索红心与战斗生命使用不同的图形与位置。
- 中央：8×8 棋盘，六类基础棋子为所选四属性、星声与护盾。元素以颜色加独立轮廓辨识；特殊效果叠加在球种之上。
- 右侧：敌人纸偶、名称与生命条，下方以显眼票券显示「下一次行动」、动作图标与具体数值。意图的可读性优先于装饰。
- 底部：五张扇形技能牌，牌面含圆形属性费用徽章、名称、类型和正文；结束回合为稳定的大按钮。
- 阶段：消除阶段手牌收在底部，出牌阶段展开；棋盘尺寸固定。阶段标记使用短标题与图标，卡牌可用状态由费用徽章和描边表达。

设计沿用一次消除行动、再选择出牌的流程，不增加即时攻击、共鸣槽或额外行动次数。

### 2. 探索地图

[探索设计图](../output/ui_concepts/exploration-ui-v1.png)，16:9。

顶部固定探索红心、贝币与「地图 / 牌组 / 藏品 / 规则」导航。地图在奶油纸地图上绘制分叉与合流路线，以小纸偶节点表现战斗、商店、休整、事件和终点首领。当前可选节点使用浅金外圈和清楚的状态提示，已完成与未到达节点减弱对比；状态同时依靠符号辨识。仅保留现有五类节点，初稿的精英图例已移除。

沿用项目现有节点类型、路线选择和地图滚动方式，不新增关卡机制。地图装饰不能覆盖节点点击区域或连接线。

### 3. 美术组件板

[组件设计图](../output/ui_concepts/art-components-v1.png)。

展示六属性、星声、护盾共八种图标；条纹、炸弹、彩虹三种特殊球标记；手牌模板与费用徽章；按钮的普通、悬停、禁用状态与阶段样式；英雄及敌人的团子纸偶。组件板包含全部属性，单场棋盘仍只使用所选四属性加星声和护盾。实际按下与聚焦状态在资源制作时补齐。

## Godot 落地建议

- 沿用 1280×720 逻辑画布与 16:9 缩放，检查 960×540 最小窗口。设计图用于布局与风格参考，切图时分别导出装饰、边框、图标与角色。
- 票券、面板、按钮使用 `StyleBoxTexture` 或 `NinePatchRect`；固定切片边距，避免缝线、纸角、圆形徽章被拉伸。纸张阴影使用少量半透明层，棋盘区降低纹理强度。
- 中文标题可用有纸偶剧场气质的装饰字，正文与数值使用清晰黑体。标题控制字数，正文保持行距；实际文字由 `Label` / `RichTextLabel` 绘制，不烘焙进贴图。
- 独立保留普通、悬停、选中、禁用资源。元素图标必须有不同形状，禁用状态不能仅靠降低透明度表达；敌人意图保留文本数值。
- 保持现有手牌收起 / 展开与固定棋盘布局。新增美术资源可放入独立目录，本轮概念交付不修改运行代码。
