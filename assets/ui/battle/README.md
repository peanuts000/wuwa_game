## 资源

- `stage-background.png`：独立舞台底图，含帷幕、星饰、纸城堡、双侧展台和灯笼，不含人物、棋盘、卡牌、文字或按钮。
- `paper-panel.png`：透明空白纸张，用于玩家、敌人、意图、回合标题和卡牌文字区。
- `card-art-atlas.png`：3×2 插画图集，依次为碎晶、冰盾、交叉枪、晶簇、火焰、守护盾。卡牌依据内容 ID 选取插画，多张同类牌可共用插画。费用、名称、类型、实际效果由原有卡牌控件绘制。
- `generation-prompts.json`：上述三张资源的完整提示词，使用内置 `image_gen.imagegen` 生成与编辑，原图保存在工具默认目录，运行资源已复制到本目录。

## 界面与交互

- 1280×720 逻辑画布，中央 520×520 棋盘，左右角色展台与纸质状态面板；顶部显示探索生命、真实贝币、回合阶段和工具入口。
- 出牌阶段手牌展开并覆盖棋盘下方；消除、结算及敌方阶段收起手牌。棋盘位置和尺寸保持固定。
- 棋盘复用现有属性图形、护盾和星声素材，保留特殊棋子标记、选中提示及消除动画；未采用概念图占位的属性球。
- 三个补给位显示已有补给名称，空位禁用；地图、藏品、记录、规则、撤退、牌堆、牌组和主界面仍使用原回调。
- 第四版「星辉铭牌」卡面已统一启用于战斗手牌、图鉴、牌组、奖励与商店，全部共享 CardView 默认皮肤。长描述、费用、升级效果和不可出牌原因由原逻辑维护。复合费用在左上纵向排列，数字覆盖属性图标；四项及以上延伸独立费用列以避开类别和效果文字。
- 这次没有修改战斗数值、随机结果或存档格式。
