# 角色选择 · 纸剧场

采用用户确认的第一版方案 `output/ui_concepts/character-select-2026-10-13/a-paper-theater.png`。

- `paper-theater-background.png`：内置 image_gen 编辑生成的空白舞台底图，保留左侧纸张、红色标题底板、右侧舞台和底部纸条，移除全部角色、文字及交互控件。完整提示词见 `generation-prompt.json`。
- `scripts/v2/character_select_view.gd`：1280×720 逻辑画布，随容器等比缩放。角色文字由原生 Label 绘制，属性和头像沿用已有 PNG，按钮复用主菜单票券。
- 底部每页四个角色位，第二页展示剩余三个。未开放角色置灰，已选角色描金，支持键盘焦点、悬停和禁用状态。属性球入口展示当前四种已选属性。
- `game_app.gd` 继续处理选择、翻页、属性弹窗、返回及开始探索；该文件只替换角色选择页面的构建入口。

此背景不包含设计图中的错字或数量。牌组数量以原有数据说明为准：碎晶弹 ×4、护身晶幕 ×3、交错射击 ×2、晶簇狙击 ×1。
