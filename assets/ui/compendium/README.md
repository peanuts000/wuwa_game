### 退出交互

- 右下角按钮、Esc、木牌外左键点击统一调用 `request_close()`。木牌顶部凸出的可见区域不算外部，右键不触发退出。
- 退出先禁用分类和返回按钮，取消尚未结束的入场动画，从当前姿态向上收起，三块牌错开 0.04 秒，遮罩在 0.38 秒内淡出。动画结束才发出 `close_requested` 并返回主菜单。
- 重复关闭不会重启动画；入场过程中可退出；页面销毁会取消退出回调，避免旧动画误跳转。Esc 优先关闭上层弹窗，再处理图鉴入口。
- `tests/test_v2_compendium_stage.gd -- --capture` 实际渲染测试 124 项通过，覆盖外部点击、Esc、按钮退出、动画过程、缩放下命中、重复输入及中途销毁。
