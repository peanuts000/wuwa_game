# 横向绘本地图运行资源

2026-10-11，根据用户选定的展开绘本地图接入 Godot。

## 美术资源

- `storybook-background.png`：独立书页、紫色舞台、金色吊饰和空白图例底板。背景不含节点、路线、角色、文字或可点击入口。
- `node-seals.png`：透明 3×2 图集。第一行为战斗、商店、休整；第二行为事件、奖励、首领。每格 512×512，运行裁剪区域为格内 `(48,38,440,444)`，启用 mipmaps 改善缩小显示。
- `bookmark-tabs.png`：透明书签图集，紫色活动页签与奶油色普通页签。原生按钮文字与图标独立绘制。
- `home.svg`：返回主界面的原生矢量房屋图标。
- `nav-map.svg`、`nav-deck.svg`、`nav-relics.svg`：折叠路线地图、叠放卡牌、宝石吊坠导航图标；替代地图、牌组、藏品文字，保留数量与悬停名称，移除规则页签。

以上三张 PNG 使用内置 `image_gen.imagegen` 生成/编辑；提示词保存在 `generation-prompts.json` 与 `tab-generation-prompt.json`。角色头像复用项目现有 `assets/pieces/condensation_base.png`，生命与贝币复用现有 `RunStatus` 资源。

## 运行组件

- `paper_map_theme.gd`：图集区域、纸张页签和配色。
- `paper_map_backdrop.gd`：全屏绘本与六种节点图例。
- `map_node_button.gd`：真实节点按钮、可达/已完成/当前/未来状态、悬停说明与角色位置。
- `map_view.gd`：层级映射为横坐标、分支映射为纵坐标，路径与箭头按模型绘制。
- `map_scroll_view.gd`：横向拖动、滚轮、焦点滚动与拖动防误触。

地图仍由原模型生成：新探索共 11 阶段，第 5 阶段奖励、第 10 阶段休整、第 11 阶段首领。美术与布局不重生成旧存档地图、不修改路线选择与奖励随机结果。长地图横向滚动，重新进入时定位当前进度；顶部切换标签保留手动滚动位置。商店与战斗中的路线预览共用横向地图，保留只读限制。

实际运行截图见 `output/ui_concepts/v4/`；交互覆盖见 `tests/test_v2_map_ui.gd`、`tests/test_v2_reward_map_ui.gd` 与 `tests/test_v2_shop_ui.gd`。
