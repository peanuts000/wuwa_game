# 角色选择界面设计方案

生成日期：2026-10-13。使用内置 image_gen，根据当前角色选择代码与现有纸剧场美术生成三版概念图。

共同布局：左侧角色信息和属性球入口，右侧大头像，底部返回、翻页、四个角色位、开始探索。柯莱塔可探索，其余角色置灰。

| 文件 | 方向 | 设计侧重 |
| --- | --- | --- |
| a-paper-theater.png | 纸剧场 | 紫色幕布、奶油纸张、红色票券，延续主菜单 |
| b-starlit-dossier.png | 星夜档案 | 深紫信息面板、金色星轨，与紫金卡框呼应 |
| c-ivory-storybook.png | 浅色绘本 | 米白和浅紫为主，整体更明亮 |

推荐 A 作为当前美术体系的延续。B 装饰密度较高，落地时可减少背景星饰。C 可作为更明亮的方向。

用户已选择 A，现已通过 `scripts/v2/character_select_view.gd` 接入游戏。`applied-1280x720.png`、`applied-960x540.png`、`applied-1920x1080.png` 为最终运行截图。原方案图保留作为设计参考。

原生成图存在文字偏差，例如“交错射击 ×2”被画成“交错射击 +2”，说明文案也有漏字；已在实现中使用正确的原生文字。角色和属性图标沿用项目已有资源，底图仅保留空白纸张和舞台。

验证：导航测试 58 项通过，四种实际窗口尺寸的布局测试 2470 项通过（1280×720、1920×1080、960×540、1280×960）。

完整生成提示词与参考路径见 prompts.json。
