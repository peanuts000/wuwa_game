# 横向绘本地图 · 第三版

用户同意地图改为横向，沿用其选中的初版绘本地图美术。

- 最终图：[exploration-map-horizontal-v3.png](exploration-map-horizontal-v3.png)
- 视觉参考：[reference-map-approved.png](reference-map-approved.png)
- 内置 ImageGen 提示词：[map-horizontal-prompt.json](map-horizontal-prompt.json)
- 连线修订提示词：[map-horizontal-correction.json](map-horizontal-correction.json)

路线从左向右推进，长地图横向拖动。原来的每个层级在横向设计中对应一列；总计 11 个阶段。图中为第 3 至第 7 阶段视窗，第 5 阶段三个节点均为奖励，使用相同宝箱图标和浅金色纸带强调。第 10 阶段休整、第 11 阶段首领规则保留。

奖励节点无需战斗，立即获得 15 贝币，通常提供未拥有藏品二选一。只剩一件未拥有藏品时直接获得，全部已拥有时改为总计 30 贝币。图例包括战斗、商店、休整、事件、奖励和首领六种。

顶部资源、页签与底部图例固定；节点与连线位于横向滚动区域，拖动不会触发节点选择。已完成路线采用金色实线与勾选，可选节点采用亮色描边，未来节点使用低对比与虚线。

本轮交付为概念设计图及设计说明，未修改游戏运行代码。第二版纵向地图保留，整套图片浏览页已切换到本图。
