## 共用规则

四版均以第 3 回合出牌阶段作视觉对比：中央 8×8 棋盘，四种选定属性加星声和护盾共六类棋子；左侧角色、生命、格挡、攻击、经验、六属性技能点及三格补给；右侧敌人生命与下一次行动；底部五张手牌、抽弃牌堆与结束回合。示例数值来自现有规则，不是平衡调整。

消除阶段沿用同位置、同尺寸的棋盘，收起手牌；本轮未单独生成消除阶段图片。地图和主界面的既有实现保持原状。

## 选型与落地

A 最接近已确认地图；B 增强场景层次；C 强调深色对比；D 简化装饰和边框。实现时文字、生命条、费用和棋盘必须由原生控件及游戏模型绘制，不能把整张概念图直接作为可玩界面。图中贝币图标仍是概念占位，接入时复用项目现有银色贝壳资源；小字、属性图标与卡牌文案以实际资源及配置为准。
