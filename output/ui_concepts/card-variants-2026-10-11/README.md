## 本轮代码修复

原先只有 BattleView 给 HandView 打开纸质样式，直接创建 CardView 的图鉴、牌组、奖励和商店走旧默认值。现在 CardView 与 HandView 默认统一启用已接入的纸质插画素材；所有入口共享同一组件，不再分别维护不同默认皮肤。2026-10-12 已采用 D「星辉铭牌」，公共控件同步更新，实际截图见 ../card-starlit-2026-10-12/。

复合费用沿用 VBoxContainer，数量 Label 覆盖同一徽章内的属性图标；四项及以上为费用保留贯穿左侧的区域，类别和效果文字向右让位，六项费用按卡高压缩间距内的徽章高度。实际费用读取原 catalog.cost，没有硬编码双费用或修改扣费规则。

新增/扩展回归检查覆盖默认素材一致、零费用与 1/2/3/6 属性列、数量叠加、卡框边界以及费用与类别/描述不重叠。

卡面测试通过；牌组 215 项、奖励 459 项、商店 446 项检查均为 0 失败。这些检查同时覆盖卡牌实例、费用、实际效果、购买/领取和存档恢复。

图鉴实际图形回归通过 1077 项检查、0 失败，覆盖四种窗口尺寸；已查看[图鉴统一卡面截图](compendium-unified.png)。`git diff --check` 通过。
